# 前车减速与跟车制动

测试前方 SUV 减速时 ADS 的跟车间距和制动响应。

实测：前车明显减速，ADS 制动并出现停走，最小净空约 1.19 米，未发生接触。

局限：ADS 映射至原报告中的后车；前车目标速度由 3.8 降至 2.4 m/s，实测峰值减速度约 3.71 m/s²，不声称复现原报告中的完全停车。

主入口为本目录 scenario.xosc，地图引用为 map.xodr。source/ 为原始事故材料，evidence/ 保存完整实跑视频、日志、轨迹和运行时代码。该例是事故启发的 ADS 测试变体，速度、触发窗口和间距的变化见 manifest.json；没有完成原始事故逐细节重建验收。
