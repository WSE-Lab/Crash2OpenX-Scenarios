# Crash2OpenX 场景测试进展

围绕上次讨论的 42 例事故场景转换任务，本轮从现有框架生成结果中选出 10 个不同原始案例，形成可查看地图、运行测试并核对实测证据的交付集。

本轮重点是测试交互时机：同向切入和前车减速按 ADS 的实际净空启动，路口来车结合生成路网的冲突位置设置出发窗口。每次改动均保存原始种子与实验参数，ADS 保持 InterFuser 自主控制。

| 编号 | 场景 | 本轮观测 |
|---|---|---|
| 013 | 邻车切入与前方骑行者 | ADS 制动但仍与切入车发生接触。 |
| 035 | 左转与横向直行冲突 | 横向来车与 ADS 接触；ADS 转弯过程中也出现短暂车道偏离。 |
| 038 | 卡车邻车部分侵入 | 卡车制动，最小净空约 3.73 米，未发生接触。 |
| 055 | 横向车辆右转并入 | NPC 右转后与 ADS 接触。 |
| 097 | 路侧车辆并线 | ADS 有制动，仍与并线车辆接触。 |
| 120 | 大型车辆路口转弯 | 转弯车辆与 ADS 接触。 |
| 135 | 三车路口横向冲突 | 横向 SUV 与 ADS 接触；运行后段有车道偏离。 |
| 144 | 转弯时骑行者切入 | 最小净空约 1.84 米，ADS 制动且出现车道偏离，未发生接触。 |
| 262 | 前车减速与跟车制动 | 前车明显减速，ADS 制动并出现停走，最小净空约 1.19 米，未发生接触。 |
| 293 | 对向左转起始冲突 | 对向车辆开始左转时与 ADS 接触，ADS 制动至停止。 |

这些结果展示的是事故材料转化为 ADS 测试刺激的能力。碰撞与车道偏离如实记录；未碰撞案例可以用于分析制动和避让表现。每例只有一次对应参数下的实跑，不能推导稳定失效率，也不能声称完整重建了原始事故。

附件中每例都有地图、测试文件、原始事故 PDF、完整视频、日志与轨迹。建议下一轮按相同种子重复测试，检验结果是否稳定。
